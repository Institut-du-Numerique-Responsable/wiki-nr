# Traductions espagnoles du cadre réglementaire européen

Statut : préparé et prévisualisé le 11 septembre 2026, non publié.

Trois nouvelles fiches : Cyber Resilience Act, NIS2 et Data Act. Les traductions conservent le lien avec les TI responsables : maintenance et durée de vie, continuité et ressources, réversibilité et évaluation des migrations. Les sources européennes sont indiquées dans chaque texte. Six modifications FR/EN ajoutent les liens réciproques vers les traductions espagnoles.

Les neuf prévisualisations ont réussi. Les révisions de départ et empreintes sont dans `publication.json`, les originaux dans `before/`. Le lot est distinct des 19 corrections multilingues préparées auparavant. Les contenus proposés relèvent de CC0 comme les contributions éditoriales au wiki.

Publication sur le serveur :

```sh
sudo python3 /home/ggallon/wiki-drafts/2026-09-11-es-regulation/publish.py
```

Le script contrôle les conflits de révision et relit chaque page enregistrée. En cas d’échec, il interrompt le lot ; une relance reconnaît les pages déjà publiées. Après publication, vérifier les neuf pages et actualiser l’export GitHub.
